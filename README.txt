BANK ACCOUNT SYSTEM (Java, OOP)

HOW TO RUN (Command Line)
1. Install JDK 8 or above. Check with:  javac -version
2. Unzip the folder and open a terminal inside BankSystem
3. Compile:
   Windows : javac -d out src\*.java
   Mac/Linux: javac -d out src/*.java
4. Run:
   java -cp out Main

HOW TO RUN (IntelliJ / Eclipse / VS Code)
1. Create a new Java project
2. Copy all files from the src folder into the project's src folder
3. Open Main.java and click Run
